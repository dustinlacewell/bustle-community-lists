## What is this?

This is a collection of various community managed lists of YOMI Hustle mods.

## How to use it?

You can either browse the lists directly, or use the [Bustle Mod Manager](https://github.com/dustinlacewell/bustle) which can display the lists in a more user-friendly way.

Bustle can also be used to subscribe and unsubscribe from these lists.

## Who creates these lists?

These lists are created and maintained by members of the [Bustle Modding Discord](https://discord.gg/yomimodding) through discussions in this repository's [issues](https://github.com/dustinlacewell/bustle-community-lists/issues).

## How to contribute?

Visit the [Bustle Modding Discord](https://discord.gg/yomimodding) and join the `#balance-discussion` channel.

You will need a GitHub account to participate in discussions and create issues.
